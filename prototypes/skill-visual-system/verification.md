# 视觉概念与样机验收

日期：2026-09-09。范围：独立静态图集及先期三主题的 HTML/CSS 样机；不包含生产 App、真实评级、授奖或 3D shader。

## 概念原画

- 三张精灵冒险原画均保存到 assets，尺寸及 SHA-256 与 adventure-provenance.json 一致；生成提示词与装备页文字修订提示词已保存。
- 同一依赖镜头的象牙环、青色镜片、深蓝握柄和珊瑚标记贯穿四档；C 保持完整，R 局部折光，SR 金框，SSR 增加重连环纹章。
- 装备页底部错误的“本次卡组”已通过 image_gen 修订成“等级材质对照”，避免暗示同一 Skill 的三档可重复装备。
- concepts.html 三个选择按钮、图片、说明和原尺寸链接同步；键盘 Enter 可切换。390 CSS px 窗口无横向溢出，三图均加载成功。
- SSR 展示仅用于设计评审；静态分镜没有被标为已经实现的视频或产品动画。

## 材质交互样机

实际通过 CUA 控制 Codex 内置浏览器，结合截图与只读 DOM 核验：

| 项目 | 结果 |
|---|---|
| 三种先期主题切换 | 图片正确加载，SR 金色独立于主题配色 |
| C/R/SR 材质 | C 素面；R 仅图像局部遮罩折光，文字区保持清晰；SR 独立金属压边 |
| 卡片翻面 | 可查看证据摘要，正反面各自可读；修复双重 180° 旋转相互抵消 |
| 隐藏 SSR | 全新 origin 演示记录中为 C；SSR hidden=true、computed display=none |
| SSR 提前关闭 | 首次点击演示后立即关闭仍保留 SSR，焦点回到触发按钮；刷新后仍显示 SSR 与“本场景待验证” |
| SSR 正常/低动态演示 | 正常结束显示“新连接已成形”；关闭动效时直接显示最终原则；Escape 可关闭 |
| 常规晋级 | 触发时 C 且按钮忙碌，结束为 SR 且恢复操作 |
| 入库/卡组 | 新卡只新增 C；方法与新卡可分别移除，计数回到 0 |
| 窗口宽度 | 390、1024、1280 CSS px 均无横向溢出；390 下主卡 285 px 宽、方法标题 25 px |
| 浏览器日志 | 本轮检查没有 error/warn |

SSR 的保留仅是 sessionStorage 演示记录，不是生产级永久授奖。用户手动选择普通材质是预览，不撤销突破记录。系统 reduced-motion 的 CSS 和指针保护已检查代码，交互核验使用页面的“动效：关”；未模拟操作系统设置。

## 静态检查

- `node --check app.js`、`node --check server.mjs`、concepts.html 内联 JavaScript 语法通过。
- 页面 `/`、`/concepts.html` 与三张新原画 HTTP 200、MIME 正确。
- 使用直连本机、禁用代理的 curl 访问非法编码路径，返回 HTTP 400，服务保持可用。本机代理会关闭该错误路径的连接，不能用代理表现代替服务结果。
- 未修改生产 src、package 或 Vite 配置，未为纯原型重复执行完整 Tauri 构建。
