# 3D 样卡验收 · 2026-09-09

最终交互以用户最新指令为准：鼠标随动、移出回正、点击卡体翻面；移除自动赏卡、拖拽、独立翻面按钮及所有闲置动态。

## 资产与模型

- 四层均为 1024×1536；subject/text 有真实 alpha，主体透明约 70.7%，不使用绘制的棋盘格。与网页复制文件的 SHA-256 一致。
- 线描从获授权的同一主体像素提取，保持严格注册；原始 RGB 文件保留。
- Blender 4.5.13 LTS 已按官方 SHA-256 校验，项目内安装。card.blend 内图片打包，图片平面 X=90° 未应用，保存了中文界面配置；本轮未要求或声称验证 Blender GUI。
- GLB 为 23,668 bytes，3 meshes、5 primitives、520 个 position vertices；四个必需材质角色均在文件中。
- Blender 正面与两侧渲染均实际完成，720×1000，Cycles/Metal GPU，20 samples。离线渲染是镭射母版；网页按 GLSL 重建并新增等级门控，不承诺像素相同。
