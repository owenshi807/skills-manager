# Card Master Foundation 产品表面

> 状态：当前产品裁决。先收敛用户能看到和操作的对象；上游 Skills Manager 的数据库、命令与迁移保持兼容。

## 1. 当前定义

Card Master 的 Foundation 是：**帮助用户看清、整理并安全管理自己与 Agent 共同形成的 Skill 能力基础。**

当前只保留直接服务这个定义的对象：

| 对象 | 回答的问题 | 当前产品位置 |
|---|---|---|
| Skill | 我实际有什么？ | 技能库「全部」 |
| 关系组 | 这些 Skill 之间是什么关系？ | 技能库「整理」 |
| Organization Case | 哪些关系还需要判断或处理？ | 技能库「待处理」 |
| 来源 | 这份 Skill 从哪里来、能否更新？ | Skill 事实 |
| Agent 投放 | 哪些 Agent 现在能看见它？ | Skill 事实 / Agent 视图 |

关系组不是 Preset，Preset 也不是卡组。前者描述“这些 Skill 是什么关系”，后者描述“把哪些 Skill 投放给哪些 Agent”。混在一起会让分类、整理与执行状态互相污染。

## 2. 当前隐藏对象

### Preset：隐藏

上游 Preset 的实际能力是批量保存并应用一组 Agent 可见性状态。它不会理解 Skill 的语义，不会帮助 Agent 自动选择任务，也不是能力分类。

当前没有验证用户需要频繁切换整套投放状态；因此隐藏：

- 左侧 Preset 列表及创建、重命名、删除；
- Skill 卡片的“启用”开关、Preset 排序与名称标记；
- Agent 视图中的 Preset bar；
- 帮助入口中的 Preset 教程。

现有 Preset 数据不删除，底层 API、数据库和 migration 不改。

### Tag：隐藏

Tag 是用户手工写入的任意标签，不是已证明的 Skill 关系。当前整理页已经用可解释事实形成关系组；同时保留 Tag 会重新制造第二套分类系统。

因此隐藏 Tag 的筛选、显示、单项编辑、批量编辑和帮助格式。既有 Tag 数据保留。

### Project：隐藏

上游 Project 是一个本地工作目录及其 Agent Skill 投放位置，不是 Skill 分类。当前产品先闭合中央技能库、来源与 Agent 投放三层事实，不引入第四套工作区对象。

因此隐藏 Project 导航、创建/删除、Skill 详情关联、设置中的 project-relative path 和直接路由。既有 Project 数据保留。

## 3. Preset 重新开放的唯一合法定义

只有真实使用证明用户需要“重复切换同一组 Agent 投放状态”时才重新开放。届时对人名称使用 **Agent 投放方案**，简写 **投放方案**，不用 `Preset`，也不用“卡组”。

定义：**投放方案是一份可复用的期望状态，明确哪些 Skill 将对哪些 Agent 可见。**

它只回答执行问题，不承担整理和认知问题。交互必须是：

1. 从当前 Agent 投放状态或明确选择创建方案；
2. 应用前预览会增加、移除或保持哪些投放；
3. 用户明确应用；
4. 完成后显示实际结果和偏差；
5. 支持恢复应用前状态。

Tag 若未来重新开放，名称为“自定义标签”，只服务搜索和个人标记；Project 若重新开放，名称为“项目范围”，只描述投放范围。二者都不得嵌套进投放方案，也不得冒充 Skill 关系。

## 4. 工程约束

当前用户表面由 `CARD_MASTER_PRODUCT_SURFACE` 集中控制。关闭功能代表 UI 不读取它来决定排序、状态或动作；不是删除上游实现。未来开放必须先更新本产品定义与验证证据，再逐项打开，不能直接恢复整套上游界面。

## 5. 场景卡：本轮 Foundation 目标

场景卡以一个稳定工作场景为单位，帮助用户按任务目的整理与衡量能力组合。它消费 Skill、内容和检查点作为材料，但不把每个 Skill 自动变成卡；同一 Skill 可以服务多个场景。新材料服务同一任务目标时更新原场景，只有目标与成功标准独立时才新建场景。归类不确定的材料保持待归类。

评级只看完成该场景任务的整体证据，不能由成员数量、平均等级或最高等级推导；没有审核证据一律未审。场景卡不替代来源事实、Skill 摘要、Agent 投放或个人能力评价。主程序Portal已消费正式场景与归属接口，细节与验收见 `prototypes/toy-wilds/SCENE-CARDS-V1.md`。当前没有审核记录的场景显示未评定；不引入新评级引擎、批量生成管线或运行时编排。
