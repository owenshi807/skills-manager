# 凡、灵、天、圣：Skill 器物绘图内核 v1.1

日期：2026-09-09。状态：已固定的参考基础与 Agent prompt 合同；不是原著设定汇编、实际授奖或已完成的运行时改造。文件路径保留 v1，当前修订为 v1.1。

**凡凭器，灵载法，天应势，圣成域。** 四品区分的是器物与世界的关系：凭材料工作 → 内含方法 → 回应情境 → 将一次方法突破表现为独有领域。轮廓、内部结构和空间关系先成立，镭射最后加入。

用户已确认以凡、灵、天、圣为参考基础，并明确扩展圣品：器物可以与背景、生灵、龙兽和环境联动；圣品后仍持续个性化演变。规范服务用户自己的 AI Agent 制图，以鼓励探索为主。独有领域是圣品的核心，器灵、宇宙、生灵和复杂动效均可选。

**固定品阶含义，开放领域创作。** Skill 审核 AI 依据方法与实例给出品阶结论；绘图 AI 将结论变成用户自己的器物和世界。一个简单、完整、有特色的静态版本就能作为起点。

## 1. 研究结论：借用类型语汇，定义由我们负责

先校正一个对象：《斗破苍穹》的天地玄黄主要划分功法、斗技。原作第二章的公开英译将两者都列为四阶，不能直接引用成通用武器等级。[原作第二章](https://www.wuxiaworld.com/novel/battle-through-the-heavens/btth-chapter-2)；阅文游戏的官方改编资料同样以功法系统介绍黄阶至玄阶等变化。[官方功法系统](https://www.taptap.cn/moment/503942686953177449)

本轮没有找到跨作品统一的「凡—灵—天—圣」四阶定义。作者自设体系会变化：晋江作者夜明琉璃在《沧月魅影》的设定章中使用凡器、灵器、圣器，材料与其世界观中的道意参与分层；其中低阶器物也能有灵识。这个反例足以说明「灵识只属于某一固定等级」不能当成小说行业规则。[作者设定章](https://www.jjwxc.net/onebook.php?chapterid=29&novelid=3200374)

器灵本身确实进入了商业游戏的器物表达，例如《鬼谷八荒》官网列有 2021-06-15 的「法宝·器灵」版本公告；它支持器灵可以作为独立设计维度，不提供我们四品的统一定义。[开发商官网公告索引](https://www.dahuangwangluo.com/)

因此，下面三种信息必须分开：

| 信息性质 | 本轮可以说什么 | 不能推出什么 |
|---|---|---|
| 原作、官方资料事实 | 某部作品如何命名功法或器物，是否设有器灵系统 | 全行业采用同一分类 |
| 类型母题的抽象 | 材料、器内机制、天地联系、领域、器灵可以组成视觉词汇 | 古代经典或小说已经规定我们的四阶 |
| 本产品原创规则 | 凡凭器、灵载法、天应势、圣成域；以下造型和特效权限 | 这些定义是作者原话或官方认证 |

检索使用原文章节、作者发表的设定、游戏官方内容，不以百科混编和同人汇总补成伪统一标准。范围是定向研究，不是对全部玄幻作品的穷尽调查。

## 2. 取得视觉资格后的四品创作参考

以下表格指导美术表达，不判断获奖资格。SSR 成就先依据方法证据成立，画师再把它表现为圣品；领域、结构或素材尚未画好，只意味着还有可探索的空间，不得阻止解锁、延迟授奖或收回已有成就。高阶的结构、材质和空间关系应更有表现力；不规定零件数量、领域规模、图片完成度或动画复杂度。无需先制作完整四张进化图，直接创作当前品阶即可。

| 品阶 | 器物到底多了什么 | 建议表达的变化 | 器物与背景的关系 | 特效权限 |
|---|---|---|---|---|
| **凡 · 凭器** | 靠材料与工艺完成明确用途 | 单一主功能；支撑、连接、握持关系清楚；木、铜、石、普通玻璃均可精致 | 在世界里：工作台、布面、石台或自然地点，背景衬托物体 | 普通反射与卡厚；无镭射、金箔边、发光纹路、时间循环 |
| **灵 · 载法** | 器物内部形成可复用的机制 | 比凡品新增真正有用的结构：校准副镜、内嵌回路、调节关节、滤芯或共鸣腔；至少能指出一条输入到输出的路径 | 内成系统：背景仍是局部场所，材料纹路与器内机制呼应 | 多层视差、普通晶体折射与材质高光；无镭射、无自发光、无游魂、无时间循环 |
| **天 · 应势** | 根据不同条件组织内部方法，和外部环境发生有意义的联系 | 多个可辨部件承担不同作用；分支、门限、取舍或可关闭路径可见；至少一条关系延伸到环境 | 器应外界：风向、水流、地层、光路或星图响应器物，但环境保有自己的结构 | 装备局部镭射、细金边、随鼠标的深层视差与局部关系响应；静止无时间循环 |
| **圣 · 成域** | 一次突破留下独有原则，器物与领域此后还能演变 | 保留器物身份和永久成就记号，用一条容易理解的联系表现自己的领域；可继续加入结构细节、栖息地与生灵 | 器物与一片天地共同成形：可以是一潭水、一座山、一方庭院，也可以是天球；关系可以是守护、栖息、滋养、共鸣或通路 | 可用全卡镭射（避开文字）、独有纹章、器内和领域慢运动、背景生灵偶尔出现；也允许完整静态版 |

这些是表现权限与美术要求，**不是根据图像反算 Skill 的能力，也不是新增授奖门槛**。例如圣品画出领域，是解释获奖突破的视觉方法；不要求 Skill 实际拥有自主智能、创造宇宙或解决所有问题。

三个不能省略的断层：

1. **凡到灵：从一件工具，变成一个方法装置。** 加宝石、换稀有木材不算结构升级。
2. **灵到天：从内部执行，变成能表达条件选择。** 更多齿轮不等于更会判断；应让不同路径、外部条件及其关联可见。
3. **天与圣的视觉差异：从回应现有关系，变成呈现某次新原则造成的重组。** 天品借环境显能，圣品让环境呈现自己的独有秩序。圣品的解锁仍可直接发生，不要求先走完凡灵天。

每一级保留同一装备的身份锚点，并有自己独立的原画。关闭所有光效、缩成小图、改成灰度，仍应看出结构丰富度和空间层次的差异。凡品完整耐看；高阶增加结构层次、材质细节和叙事关系，不能靠污损低阶制造高级感。

## 3. 品阶、元素、画风、器灵与领域生灵

**品阶决定器物怎样与世界发生关系；元素决定用什么现象讲；画风决定怎样画；器灵描述器内生命意象；领域生灵描述谁在这个世界栖息与行动。** 这些维度可自由组合。下表是可扩展的参考词汇，不是封闭白名单；生命、菌落、声音、梦境等也可以成为母题。

| 元素母题 | 器内语言 | 天品：回应环境 | 圣品：形成自己的领域 |
|---|---|---|---|
| 大地／矿物 | 地层、承重、晶脉、砝码 | 识别地势与受力，将关系接入器物 | 一块有边界的山河剖面围绕核心重排；晶脉在山体与器物间接续 |
| 水／冰 | 滤膜、流路、凝结、折射 | 分流、合流与潮位条件对应不同通路 | 器中水系延展为独立流域，局部潮汐遵循同一新路径 |
| 木／生长 | 年轮、枝脉、嫁接、根系 | 因环境改变生长方向与支撑 | 由器心生出层叠林域，根冠之间有可追踪的关系 |
| 火／热 | 炉腔、淬炼、热交换 | 热量与供给条件驱动分工 | 一个围绕器心形成的锻造领域；热流和熔层有去处，不是全屏火焰 |
| 光／晶体 | 镜片、棱镜、遮断、分光 | 相同输入在不同条件下分路、过滤或止步 | 重构后的光路连接器内晶体与有边界的光学空间 |
| 星象／空间 | 轨道、坐标、尺度、重力 | 与外部星图关系对应 | 轨道从核心延伸到专属天球；远近尺度呼应同一原则 |

这是美术母题表，不采用五行相克或战斗数值。凡品也能刻星图、使用陨石材料；圣品也能是一件大地系器物。**出现宇宙，不自动高级；出现大地，不自动低级。**

器灵规则：灵品的「灵」表示器内成法，不默认有意识。天品可以有非生命的能量节点，暂不开放游动神魂。圣品可选无器灵、抽象神魂或附着器物的伴生灵。核内神魂遵循核心遮罩；器外伴生灵沿自己的附着区域活动。

**领域生灵是另一层。** 龙、动物、山岳巨猿、守护者可以在背景里有自己的栖息地、路径和行为，不需要关在晶核中。普通动物可以出现在任何品阶的静态背景里；大型生灵、龙或神话形象的出现也不会自动提升品阶。圣品开放它们与器物、领域的联动及可选局部动态。生灵与器灵都是卡画内容，不自动创建另一个 Agent，不进入人的 Profile。

### 3.1 圣域联动：选一个喜欢的联系就能开始

| 可选关系 | 静态图就能表现 | 想增加动态时 |
|---|---|---|
| 栖息／守护 | 龙盘在器物映出的水域旁；巨猿守在与器物相连的山门 | 龙缓慢抬首；巨猿偶尔从雾后走出，停驻后退回山体遮挡处 |
| 滋养／共生 | 器物流出的水形成一潭水，附近草木与动物栖息 | 水流缓慢推进，叶片轻动，小动物来饮水 |
| 共鸣／回应 | 器物刻纹与生灵、地脉共享一种纹理或形状 | 鼠标靠近某区域时，生灵转头或局部纹理回应；无需整卡发光 |
| 通路／空间 | 器物开口与背景山门、水路或林间小径相接 | 生灵沿既定路径出现和离开，层间遮挡形成深度 |
| 历史／生长 | 后续版本中新枝长出、栖息地扩展，旧纹章仍可辨 | 用户主动生成新版本；不因现实时间经过就强制自动变形 |

这些关系可以是叙事、形状、色彩或空间上的呼应，不要求真实物理模拟，也不要求每个动物行为都能逐条解释 Skill 方法。首次推荐一个联动点，用户也可先做一件器物与简单领域。龙、巨猿和神魂都不是必填，关系数量不计分。

将用户说的「金刚」意象转成原创山岳巨猿守护者，就是可直接采用的一例；它有自己的山体位置、出入路径和停驻姿态。无需为此增加召唤、战斗、养成数值或 NPC 系统。

### 3.2 圣品之后：同品演变

永久保留的是那次 Skill 突破成就；可以持续变化的是它的器物与领域表达。新方法细节、用户主动表达的审美、使用主题和新的创作灵感，都能带来新的形态、材质、背景、生灵和联动。

同一张圣品可以从「器物与一潭水」演变为「龙栖水域」，再变为「山河与龙共同回应器物」；也可以主动收敛为更简洁的版本。它们同属圣品，不增加圣一阶、圣二阶或 SSR+，不要求再次证明突破，不以像素、粒子或生灵数量计算经验。

每次变化保留可识别的装备身份与成就出处，旧画可作为参考。若用户不喜欢新版本，可以继续采用旧画；这不改变成就。Skill 的当前能力和适用范围另按实际版本判断。纯视觉重绘不触发能力重审；内容变更需要核对当前适用性时，也不重置圣品成就。这里固定的是生成与迭代约定，未实现资产历史或自动生成系统。

画风仍可换成精灵冒险图鉴、东方山海、机械科考、矿物版画等。先冻结四品结构差异，再重绘材质和笔触。无需因品阶用中文，就把全产品改成传统修仙手游。首套继续沿用当前清晰、可收藏的冒险器物语言。

## 4. 当前「依赖镜头」如何落图

身份锚点：圆形观测口、握持或基座结构、刻度定位点、用于检查关系的镜头家族。不是每级保留完全相同的外轮廓。

| 品阶 | 器物形态 | 画面必须讲清的事 | 背景 |
|---|---|---|---|
| 凡 · 素木放大镜 | 单镜片、木柄、铜连接件 | 能看清局部对象；完整但没有额外判断结构 | 研究桌与局部材料 |
| 灵 · 双轴勘察镜 | 副镜、双轴支架、校准刻度、可追踪的器内光路 | 一次操作能沿固定机制检查关系 | 工作台或克制的观测室；副镜结构可辨 |
| 天 · 三相解析镜 | 三片异向棱镜、解析架、开放支路、止步节点 | 区分同源转述与独立证据；不是每条来路都等权进入核心 | 外部多路光进入器物，其中同源光先合并、反证保留独立通路 |
| 圣 · 万象重构镜 | 旧闭环打开、晶核与开放轨道重组、独有重连纹章 | 情境判断与机械保证重新分工；突破已经改变工作法 | 领域光路与器内结构同构；硬边界稳定，判断路径开放可变；可用宇宙，也可用山河 |

后三行是方法到造型的设计解释，不是正式发牌。此前哲学审计对依赖镜头有一次突破资格结论，但尚未绑定管理器里的确切卡片并授奖。[证据与限制](skill-rating-philosophy-audit-v1.md)

当前原型已有四件独立器物和 SSR 晶核／宇宙神域。凡品形态与灵品双轴结构可继续用；天品下一版应把「器物—环境的条件关系」画得更明确，不能只增加金属架；圣品已有开放轨道和神域，但应继续强化器内、器外的同一重组关系。**本轮交付定义与提示词，不声称上述新构图已经全部重绘上线。**

一个跨主题反例：商业判断可以用秤作为家族。凡品是普通秤；灵品加入统一成本的校准结构；天品将不同机会与约束接入独立衡量臂；圣品把一次已证实的新资源分配原则表现为「群山地层围绕秤心重新平衡」。不需要水晶、神魂或宇宙，也可以有足够丰富的圣品结构和局部地脉流动。

## 5. 与知识库和既有评级的关系

| 视觉品阶 | 对应原记录 | 用我们自己的知识流程理解 | 不可省略的限制 |
|---|---|---|---|
| 凡 | C · 基础／待验证 | 资料或方法已入库，尚未取得更高等级的充分证据 | 待验证不等于弱、不等于劣于市场；Karpathy 原方案不能被贬成只有文件夹 |
| 灵 | R · 成法 | Ingest、审核、蒸馏与发布能够形成可复用、可追溯的闭环 | 不能因有这些模块就自动判 R；实际方法收益需要对应证据 |
| 天 | SR · 通理 | 能选择蒸馏重点、处理来源冲突、决定何时重开原文和何时停止 | 碰撞模块、更多检索关系本身不是 SR 或 SSR 证明 |
| 圣 | SSR · 隐藏永久突破成就 | 某次碰撞或改造产生新的有效区分，落入 Skill，并实际改变判断或行动；依赖镜头是审计示例 | 不是整个知识库、所有组合成员或持卡人都成圣 |

流程不是等级流水线：Ingest 也能发生突破，Collision 也能只有普通拼接。不存在「入库=凡、蒸馏=灵、碰撞=圣」的自动授奖映射。具体知识库事实沿用此前审计的本地证据；本轮未重新运行其测评，未扩充全行业排名。

数据仍然是**三个常规当前等级 C/R/SR，加一个独立的永久 SSR 成就**。凡灵天圣是四种卡面表达，不新增四级经验条：

- 一次已成立且已进入 Skill 的实质突破即可解锁圣品，无需先取得天品。
- 合法成就永久保留；当前版本待验证或不可用时，圣品外观与纹章仍保留，当前状态另显。
- 默认未解锁时隐藏圣品，不展示预留槽、锁头、概率、刷次数进度。
- 导入、分享与组合的成就归属沿用评级基础；持有圣品不证明本人会用、原创或悟道。
- 卡面示例：`圣 · 万象重构镜`，说明 `SSR 突破成就 · 依赖治理`，另列 `当前场景：待验证`。

品阶命名不改变原评级基础中关于证据、身份、范围与永久性的规则。[评级基础](skill-rating-foundation-v1.md)

### 审核 AI 的姿态：帮助方法长出来

目标是让用户容易理解并接近圣品。审核 AI 先指出已经做对的地方，再给明确的品阶与简短依据；尚无充分依据时，只提出最有价值的一个小改进或一个对照实例。它不评用户本人，不以精英身份、行业原创、调用次数或反复突破抬高难度。

认可一次实质突破仍需要看清旧方法、新区分已进入 Skill、一个改变判断或行动的实例及边界。已有材料足够就直接给出支持结论，不为了仪式感追加作业；材料不足也不编造通过。用户不需要先完成一套庞大的 benchmark 或四张进化原画。

审核结论交给绘图 AI，绘图 AI 不根据画面绚丽度改级。新审核支持的圣品结论与产品已保存的成就记录区分；已有合法成就直接沿用。提示词可以准备结果，但不能把未接通的生产授奖写成已经发生。[可直接使用的 Agent 主提示词](visual-foundation/agent-prompts.md)

## 6. 从定义到图层、3D 与动效

生成公式：**审核结论 + 用户想法 + 可选旧图 → 器物身份 → 品阶语义 → 一句领域创意 → 静态原画 → 按需分层与动效 → 同品继续演变。** 用户无需填写复杂表格，Agent 能推断的细节直接补齐并标注创作选择。元素、画风、生灵和联动都是可选扩展。

默认交付静态完整原画与一条下一步建议；只有需要动态或可交互 3D 时，才制作下表对应图层。下表是技术导出要求，不是普通用户拿到图的门槛。

| 交付层 | 必要内容 | 验收重点 |
|---|---|---|
| 主体 | 独立器物原画、真实 alpha | 四品造型分别成立，连接、支撑与遮挡清楚；不能把棋盘格画成透明 |
| 背景 | 无主体的独立场景 | 天品表达环境关系，圣品表达领域与器心的同一规则；留文字区 |
| 线描与材质遮罩 | 与主体像素对齐的 lineart、foil mask | 凡／灵 foil 为空；天仅器物指定部位；文字与大面积镜面保留 |
| 圣品可选动态层 | 按实际选项提供核心 mask、领域前后景、核内器灵、外部生灵；成就纹章独立排版 | 核内运动不漏出晶体；外部生灵有独立位置、遮挡和路线；不因核内限制禁止背景生灵 |
| 文字 | 程序排版的品阶、名称、状态、证据入口 | 不烘焙进画作；不被镭射盖住；减少动态时仍能识别 |
| 3D | 卡体厚度、图层深度、透视与交互；需要绕物观察时再做器物体积模型 | 2.5D 插画分层不能宣称器物本身已是真实 3D；不以旋转视频代替可把玩的卡 |

动效规则延续用户决定：鼠标位置驱动轻微倾斜，移出回正，点击或键盘翻面；不增加卡背操作按钮。不自动整卡旋转、扫光或闪烁。凡／灵／天没有静止时的时间循环。

圣品允许器内元素、神魂与领域的低速局部运动，也允许背景生灵偶尔出现或随鼠标回应，不能改变整张卡的姿态或亮度。起步推荐只激活一个联动，其他部分静止。内部运动约 8–14 秒、领域约 20–35 秒是已有原型的调参参考；生灵不必照这个周期，也不必常驻循环。只激活正在检视的一张卡；手动暂停、减少动态、背面、离屏或页面隐藏时冻结。减少动态时显示自然的静态姿态，生灵与其领域关系仍可读。现有模板提供素材与 Blender／Three.js 工作流，品阶、神魂和授奖逻辑由本产品定义，不假称 Skill 自带这些预设。

一次新成就的揭晓仍按已成立的事件播放，不能将背景循环做成反复开卡；跳过、关闭动画不影响成就。此处不新增自动授奖器或事件系统实现。

## 7. 生成合同与验收

机器可读合同：[cultivation-contract.json](visual-foundation/cultivation-contract.json)。用户自己的 Agent 先使用 [审核／生成／同品迭代主提示词](visual-foundation/agent-prompts.md)，再按需参考 [四品与领域案例提示词](visual-foundation/prompt-pack.md)。案例不限制用户必须采用镜头、宇宙或同一种画风。合同描述设计权限，不被现有运行时读取，不是评级引擎。

用户侧反馈保持简单：先指出一个成立的特色，再给最多一条建议。以下内容供我们和 Agent 做参考审阅，不变成用户的七道考试；静态图只检查实际使用到的部分。只有成就误述、文字不可读、特效越级等明确问题需要纠正，其余优先鼓励保留和继续迭代：

1. **轮廓辨识：** 保留器物家族，高阶的结构或空间关系有可见变化；不要求用户先生成所有品阶来比较。
2. **功能追踪：** 指出灵品的器内方法路径、天品的外部条件关系、圣品的独有重组原则。
3. **领域联系：** 找到一句话能说明的器物—领域关系即可；仅有装饰性背景时，建议下一版补一个联系，不把整张作品判废。
4. **主题开放：** 无宇宙、无器灵、简单领域或静态版本都可以成立，不要求每张卡补齐全部元素。
5. **材质隔离：** 凡／灵在前、背、边都无镭射泄漏；光效不覆盖文字。
6. **交互与资产：** 真 alpha、线描配准、mask 不越界；停止动效仍完整；鼠标微倾与点击翻面保留。
7. **语义诚实：** 圣品可与当前待验证并存；原型明确演示；没有向 Profile 发奖或给整库升阶。

## 8. 原创与知识产权边界

可复用的目标是「通用母题 + 原创表达，不依赖特定 IP」，不能承诺「绝对无版权」。WIPO 区分思想、方法与其具体表达；文字、图画中的原创表达仍可受保护，短名称也不能一概断言不受保护。[WIPO](https://www.wipo.int/en/web/copyright/protection)

中国最高法指导案例 81 号也区分一般题材与具体选择、安排、设计；该案对象是历史题材剧本，不是对游戏品阶名称的直接裁判。本设计从中采用的原则是：不用某部作品的具体人物、武器造型、标志、叙事组合或原文设定来承载产品识别。[指导案例 81 号](https://www.court.gov.cn/shenpan/xiangqing/37642.html)

实际绘图提示词使用原创器物描述与上述结构规则，不要求复刻《斗破苍穹》、宝可梦、鬼谷八荒的具体资产或品牌风格。研究资料只用于辨清母题与分类的适用边界。本轮没有作名称商标检索，也没有法律上的零风险认定；这不成为本地原创设计的新增审批步骤。
