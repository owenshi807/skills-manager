# 四品器物与圣域案例提示词 · v1.1

配合 [绘图内核](../skill-cultivation-visual-foundation-v1.md) 与 [结构化合同](cultivation-contract.json) 使用。用户自己的 Agent 先用 [主提示词](agent-prompts.md)；本文件是可选案例库。以下是待执行的提示词，不是已生成图片或新的授奖结论。

选「共同前缀 + 一张喜欢的构图」就能开始，只生成当前需要的品阶，不要求做完整四张。四品对照服务我们的参考审阅，案例里的部件数量、神魂、画风、宇宙与生灵都可替换。先完成静态图；需要动画或 3D 时再按需分层。现有圣品每次换图沿用成就，不重审突破、不重复授奖。

## 共同前缀

> 为原创 Skill 装备收藏卡制作一张完整的器物概念原画。冒险图鉴气质，深靛墨线、干净分区上色、细腻的金属与矿物材质，温暖象牙色、深蓝、铜色与青绿主调。形态精确、收藏品完成度高。不要套用任何现成 IP 的人物、品牌、标志或标志性武器。竖构图 1024×1536，器物完整落在画幅内部，主体集中于 x=130..894、y=275..1250；顶部和底部留安静的文字排版空间，实际生成图中不要任何文字、字母、数字、水印、等级徽章或卡框。三分之四正面视角，镜头家族保留正对观察者的圆形观测口与左下握柄／基座方向。高阶器物必须以独立结构升级，不是复用低阶轮廓换色；低阶也完整精致。普通材质高光可以画，动态镭射、卡牌扫光、粒子覆盖以后由渲染器完成，不烘焙成整卡彩虹。背景必须与本张指定品阶的关系一致，不能随意加宇宙。下列视觉意象表达方法，不需要把抽象概念写成图中文字。

## 凡 · 素木放大镜（lens-fan）

> 一件可信、精致但非常普通的野外放大镜。单片略带青色的圆形玻璃镜，薄铜圈、深胡桃木直柄，两枚功能铆钉和柄尾少量深蓝织带。单一明确用途，连接与握持关系完整。木纹细腻、玻璃有普通环境反射；没有宝石核心、没有雕花装甲、没有额外镜组。它安静地放在研究桌上，附近只有几块待观察的天然材料和柔和斜光，背景退后。物体没有自发光、光环、光谱膜、金箔或灵魂。表达「靠器材本身看清局部」。不要故意破损、粗糙、廉价，也不要把桌面扩大为史诗场景。

## 灵 · 双轴勘察镜（lens-ling）

> 与素木放大镜同属圆形观测器家族，但结构清楚进化为双轴校准装置：象牙陶瓷与深蓝铜制主镜壳，右上方一枚可折叠副镜，两条实体转轴臂，一个拇指调焦轮，短皮革包柄与铜橙色卡扣。未标文字的校准刻线沿支架排列，透过局部开口能看见副镜—校准片—主镜的固定光学路径，路径用静态材质和普通折射呈现。明显的双镜、不对称轮廓，有细节但每个部件有用途。背景是克制的小型观测工作台，材质纹理呼应器内回路。没有悬浮皇冠、没有神魂、没有镭射、没有粒子、自发光或辉光。表达「方法装进了器物内部」，不能只是普通放大镜多镶一颗宝石。

## 天 · 三相解析镜（lens-tian）

> 将同一镜头家族进化为具有三相棱镜、不同朝向解析架和条件支路的精密器物。保留中央圆形镜口、深蓝握柄与铜橙定位点。三个青色棱镜位于不对称三角支架，象牙陶瓷片和细金属构件叠出清楚深度。一侧几束来自同一上游的光先在器外合并为一条通路，另一条独立光路保持独立；其中一条可关闭的支路有物理遮断片。所有关系可追踪，不能成为装饰性的蜘蛛网。背景为具有层次的峡谷光学观测场，地层和空气中的光路保有自身方向，再与器物不同入口对应。主体仍占视觉中心，远景安静。静态原画中的局部光路可微亮，不能全屏发光。只用普通金属高光和精密刻面，预留器物局部镭射位置；不要在原画烘焙全卡彩虹或闪星。没有神魂、没有围绕器物自成天地的封闭领域。表达「器物能根据外部关系选择通路」，而不是更多棱镜堆砌。

## 圣 · 万象重构镜（lens-sheng）

这是一种宇宙与核内神魂方案，不是圣品默认必选；下面的简版、水龙或守山方案同样可选。

> 将同一圆形观测器家族转化为具有独有重组结构的神器。中央十二面青色晶核由三条不完整、不同深度的象牙与古金弧环托住；右上方保留清楚的大开口，两枚棱镜通过精密桥接构件形成新的通路，深蓝分叉握柄和铜橙定位点仍可辨。结构细节、通透间隙与材质层次显著高于三相解析镜，不能只加亮。晶核深处有三条抽象、非人形的神魂流线与元素层，用不同深度和尾迹暗示缓慢游动，未来动效只发生在核内，晶面与外框保持稳定。
>
> 背景是由这件器物展开的有边界的天球领域：前后远近三层轨道与器内的开放环、桥接路径一一呼应，星尘聚集在真实通路上，一部分边界恒定、一部分路径开放分叉。器物和空间共同呈现「旧闭环打开、不同关系重新分工」；不是随意贴一张银河照片。远景有极少量安静的建筑性剪影，主晶核仍是最明确的焦点。专属突破纹章单独制作，此原画不生成文字或徽章。给后期全息材料留纯净的深色间隙，不画白爆、整卡扫光、彩虹蒙版或满屏乱飞的碎片。

## 圣 · 山河衡，大地系无器灵反例（balance-sheng-earth）

这是一张假设的商业判断 Skill 视觉预览，不声称已存在对应突破证据或已经获奖。其用处是检验「圣品不被水晶、神魂、宇宙垄断」。共同前缀中的镜头家族约束替换为秤的身份锚点，其余画风与构图要求保留。

> 一件原创山河系衡量神器，身份锚点是秤梁、独立承重臂与中央支点。青铜、玄色矿石、温暖象牙矿层与克制金属嵌线，精细而丰富。中央不是宝石，而是一枚有清楚横截面的层理石核；秤梁从单一两端比较改为三个不同长度、不同支点位置的衡量臂，结构形成一个新的分配关系，断开的旧标尺保留为可识别痕迹。器物上方与后方不是普通山水布景，而是一片从支点展开的有边界的悬浮山河剖面：河床、矿脉、承重地层与三条衡量臂各有可追踪的连接，群山在同一原则下重新平衡，几条开放出口表现适用边界。近处地层与远处峰脊形成深度，地脉以低饱和暖金色细线呈现，供后期局部慢流使用。没有宇宙、没有人形神、没有器灵、没有水晶球、没有全屏闪电。高贵和绚丽来自宏大的空间层次、精密器物结构和同一法则贯穿山河的关系。不要把它画成普通秤摆在山景照片前。

## 圣 · 镜畔一池，简单静态起步（lens-sheng-simple）

> 保留这件观测镜的圆形镜口、青铜连接结构和可辨的开放镜环，让镜片里的水纹延展到它身旁的一潭清水。池畔只有几块石头和少量草木，水面倒映镜环的独特开口，器物与这片小领域有一句话就能说清的联系。器物刻面、铜饰与前后空间保持精致，画面留白充分；没有神魂、龙、复杂建筑和宇宙。表达一件已经拥有自己领域的圣品，允许安静、小巧和完整静态。圣品成就记号以后由排版层承载，不在原画中生成文字。它是同品成长的起点，不是等待升级的残缺品。

## 圣 · 水镜栖龙，外部生灵（lens-sheng-dragon）

> 在既有观测镜家族上创作一个水域：镜片的开放环形通路与背景一条短水路相接，水路通往近处池潭。一条原创、温润而有力量的龙盘在水边的岩石上，鳞纹与镜环共享一种弧线，龙守着这条通路。龙是器物领域中的外部生灵，不在镜片或晶核内部。器物占视觉焦点，龙与水域在后方构成可辨的景深，少量植物让栖息地完整。一个清楚的守护与通路关系即可，不需要塞满世界设定。先输出静态自然姿态；无文字、无整卡镭射蒙版、无爆闪。

可选动效：鼠标靠近水路一侧，龙缓慢转头，水路局部出现细微回应；鼠标离开后回到自然停驻姿态。卡片仍只轻微跟随鼠标倾斜，不触发翻面或授奖。龙单独分层，其活动不受晶核 mask 限制。

## 圣 · 山河衡·守山，巨猿与栖息地（balance-sheng-guardian）

此例沿用秤家族身份锚点，替换共同前缀中的镜头约束。

> 保留山河衡的青铜秤梁、层理石核和独特承重臂，在背景建立一座与秤心层理纹路相呼应的山体。一位原创山岳巨猿守护者栖息在山腰石林后，先以坐在山门旁的安静姿态出现，肌理、石甲或毛色与该山体呼应。秤梁的一端与山门形成明确的空间联系，表现器物和生灵共同守护这片领域。巨猿无需占满画面；完整的山门、栖息地与器物结构足以产生力量感。背景有自然遮挡和前后层次，器物始终清晰。无文字、无全屏震动、无战斗场面，先制作静态版本。

可选动效：巨猿偶尔从原有石林与雾层后走出，沿短路径来到山门边，轻触与器物呼应的岩壁，停驻后回到遮挡处。用生灵图层与山体前景遮挡实现即可；不要求骨骼模型、物理模拟或战斗 AI。暂停或减少动态时呈现山门边的自然静态姿态。它是圣品领域里的小事件，不是开卡动画。

## 可选：确认原画后的分层生成模板

静态版本无需先完成这些模板。需要动态或 3D 的部分再单独处理。每次编辑前先查看确切参考原画；用图像工具引用其本地文件。共用画布尺寸、构图坐标和锚点，保留用户要求的身份特征。图像工具输出仍需实际检查 alpha 与配准。

**主体 RGBA：**

> 保留参考图器物原画、位置、比例、材质与遮挡关系，提取完整主体，去除环境和投影；不添加部件或改造轮廓。真实透明 alpha，绝不画棋盘格。若无法输出真正透明，则严格纯白背景且无地面阴影，供已授权的技术抠图。玻璃内部保留画出的材质与光路，不把晶核误删为空洞。无文字、卡框、整卡彩虹、外部粒子。输出与参考相同画布和像素位置。

**独立背景：**

> 保持参考图环境透视、光源和已选场景关系，只去除主体器物并补全其后的环境。不得生成第二件器物；保留原主体的位置为空间中心。顶部、底部保留安静排版区。天品保存环境来路，圣品保存领域与器物的呼应。用户选择的静态生灵可以留在环境中；需要独立活动的生灵另行提取并补全其后的环境。无文字、徽章、未经选择的角色主角或全屏粒子。

**外部生灵及前景遮挡（仅需动态时）：**

> 从参考原画提取已选龙／动物／巨猿，保留身份、姿态和比例，输出独立透明生灵层；它属于背景领域，不放入器物核心遮罩。保留其栖息地作为单独背景，并提取路径上需要遮挡它的山石、雾或树木前景。清楚记录它起始位置、短路径和停驻位置，避免经过文字区。只制作已选择的一个局部事件所需素材，不重画整套卡牌。静态版本使用自然停驻姿态。

**线描、foil mask、核心 mask：**

> 在线描与遮罩工作中严格沿用批准原画的像素位置，不重设计。线描只保留主体的结构边、光学路径和必要刻线。凡、灵的 foil mask 必须为空；天仅指定器物区域；圣可扩到领域，但文字区始终剔除。核心 mask 只覆盖需要局部运动的内部介质，排除金属框、晶体外轮廓与铭刻。每个 mask 单独输出，不能和线描或原画混成一个文件。

精确 mask 和线描可以采用用户已授权的本地技术处理；它们是为保持原画和配准服务，不能重新绘制未经审阅的主体。全息、流动、视差在渲染器中加，静态图像工具不会交付真正可交互的 3D 或可用时间动画。
