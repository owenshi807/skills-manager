- 地图、角色档案、角色独立配装、仓库与所携场景卡分离。一个已识别场景对应一张 Skill Card，成员 Skill 在手册里呈现。
- 水面闪烁修复；鼠标轻转卡片，点击或键盘翻面；不自动闪卡。简短能力说明先回答用途、使用时机和边界，细节按需展开。

- 两张端到端试点：知识场景当前 SR，突破审核 `supported`，使用圣品视觉；商业场景 R。其余场景未评定、待绘制。
- Multica 接入研究及只读探测记录归档。产品配装目前是本地状态；未接入远端执行、装备写入或任务派发。

## 交付边界

1. `supported` 不等于永久 SSR 奖章已入库，也不代表个人能力认证。当前没有自动全库评级或永久授奖服务。
2. 商业场景缺一个可读取的家族入口及真实端到端运行凭据，未凭卡面质量提高评级。
3. 两张新卡面是 1024×1536 静态原画，卡片轻转与镭射由鼠标驱动；本轮没有新增体积装备模型或晶体内部时间动画。早期 3D 原型作为参考保留。
4. 历史知识评测是审核依据，本次冻结未重新运行；公开身份 fixture 不含私有知识正文，不足以独立重放原始方法评测。
5. “复合 Skill、角色原型与 Agent 实例如何对应”进入下一阶段讨论，尚未定稿，不纳入本阶段实现和数据迁移。
