## 1. 语义锚点与当前推荐

**Skill 是可升级的装备。Agent 是装备这些 Skill、在场景中执行工作的游戏角色；它不是人的 Profile 能力、人格等级或成长替身。** 人与 Agent 必须在信息架构和画面中分开：人管理目标、资料和授权；Agent 装备方法并完成任务；Skill 的评级只描述方法及其已获认可的突破。

本轮先采用 **精灵冒险图鉴** 做第一套完整视觉方向：明亮的图鉴纸面、深海军蓝线描、象牙/青绿/珊瑚色器物，角色与装备共同出现在野外研究室。它把“选择一个 Agent，再为它装备合适的方法”说得最直接，同时让普通 C 卡也像完整藏品。此为当前推荐的首套方向，**不是用户对长期唯一主题的承诺**。

| 可换风格 | 世界与界面语言 | 保持不变 | 需要重做 |
|---|---|---|---|
| 精灵冒险图鉴（第一套） | 图鉴纸页、野外研究室、友好冒险角色与器物装备 | 四层语义、等级门控、事件身份、卡片信息结构 | 器物/角色插画、线描、foil mask、纹章 |
| 秘藏馆 | 深墨绿、象牙石、刻线与收藏柜 | 同上 | 器物插画、金属和纸张材质、线描与 mask |
| 光谱实验室 | 冷靛蓝、银白陶瓷、光学仪器 | 同上 | 场景插画、冷色材质、线描与 mask |
| 探索手册 | 纸白、靛蓝版画、朱红印记 | 同上 | 版画插图、印刷纹理、线描与 mask |
| 机甲 | 模块化装备舱、机械接口 | 同上 | 机甲装备插图、面板线描、材质与 mask |
| 像素 RPG | 像素图鉴、格点地图、像素 UI | 同上 | 全部像素资产、像素化纹章和材质表达 |
| 东方灵兽 | 山海图鉴、灵兽与器物、矿物/宣纸质感 | 同上 | 灵兽/器物插画、水墨线描、纸矿材质与 mask |

主题替换不是给一张既有插画套滤镜。可复用的是图层接口、等级门控和动画事件；每个主题都要重画符合世界观的插画、线描与局部 foil mask，确保 C/R/SR/SSR 的差异仍准确可读。

## 3. 四层视觉语义

| 视觉层 | 回答的问题 | 允许变化 | 禁止混用 |
|---|---|---|---|
| 主题 | 身处什么世界？ | 环境、字体、卡背、基础材质、场景布局 | 换主题不改变能力或成就 |
| Skill 装备题材 | 这件方法装备做什么？ | 主体器物、主构图、学科符号、短名称 | 人物头像、作者名气或 Agent 本身不替代方法解释 |
| 等级材质 | 方法目前在哪一层？ | 纸面、局部 foil、金箔、边框层次 | 相同等级跨主题仍要有同等可感知的强度 |
| 突破纹章 | 这件装备曾突破什么？ | 有意义的永久图形与一次揭晓叙事 | 不以更多粒子、亮度或更长的 S 字母代替含义 |

同一 Skill 升级必须保持装备主体可识别。高等级揭示已有结构、增加材质层和纪念纹章；不能每次把它换成另一件器物或角色。新资料、安装 Skill、改文本、调用次数都不会自动升级，只有评级或已认可成就结果变化才能产生等级或突破事件。

## 4. C / R / SR / SSR 的材质梯度

| 等级 | 静态识别 | 交互时 | 不可突破的边界 |
|---|---|---|---|
| C | 完整精致的素面印刷、普通边框、明确等级与证据状态 | 轻抬起、翻面；只表达纸张和卡厚 | 不用 rainbow、烫金框、发光刻线或稀有粒子；绝不做成廉价残次品 |
| R | 独立升级的器内结构、普通材质反射，边框仍普通 | 随鼠标变化的结构视差 | 无镭射、发光刻线或金色稀有框；无时间循环 |
| SR | 条件关系更明确的器物、细金边与环境层次 | 指定器物 mask 内的局部镭射、关系视差 | 文字稳定可读；无整卡镭射与时间循环 |
| SSR | 独有突破纹章、重组刻线/环结构、永久成就标记 | 揭晓时局部聚焦，之后回到可阅读收藏状态 | 不是把 SR 调亮；新结构与纹章必须能说清突破含义 |

文字不镭射、不发光、不被 foil 覆盖；等级不只靠渐变与金色，必须由文字、边框和纹章形状共同判断。C、R、SR、SSR 都是同一装备身份的连续形态。Agent 场景中的 C/R/SR 三张并排卡只服务材质比较，不能被解释为重复装配。

**四种卡面不是强制升级路线。** C/R/SR 描述当前方法评级，SSR 是独立且永久的突破成就；一次符合评级基础的实质突破即可解锁，不要求先刷满 SR。卡面可以采用 SSR 纪念形态，当前场景/版本的有效性仍单独显示。

## 5. 突破纹章与 SSR 的产品规则

纹章先表达证据，再成为图形：区分新情境可画分离路径；重构方法可画旧环打开、节点重连；跨域关系可画两个完整环的桥接；把反证纳入方法可画有回返路径的开放环。`依赖镜头` 采用“旧闭环打开，情境判断与机械门禁重组”为例；图形不构成突破证据本身。

SSR 永久成就默认隐藏：未解锁界面不显示锁头、“还差 N 次”、概率、进度条或预留 SSR 槽。图集的 SSR 卡与分镜仅供设计评审对照，生产界面也不应因其存在而泄露未来成就。合法解锁后，切换主题、当前版本待验证或依赖失效都不回收纹章与卡面；当前可用性另行显示。

首次 SSR 的约 2.2–2.8 秒揭晓为：旧结构打开 → 新关系成形 → 纹章留存。用户可以跳过动画或关闭动态效果，但**取消/跳过动画不能撤销已经成立的成就**；重放只是显式观看，不能重复授奖。生产实现按持久化事件身份去重，多事件排队、合并查看，且不打断用户正在输入的任务。

三种事件必须分开：

| 事件 | 首版节奏目标 | 结束后的事实 |
|---|---|---|
| 新卡入库 | 0.6–0.9 秒：进入、翻开、落位 | 新记录默认 C · 待验证，或继承可核验的既有评级/成就；显示来源 |
| 常规晋级 | 1.2–1.8 秒：收光、材质形成、等级落定 | 对应真实 C→R 或 R→SR 的评级变化，说明新增能力与依据 |
| 首次 SSR | 2.2–2.8 秒：聚焦、结构重组、纹章揭晓 | 一次被认可的 Skill 突破，成就先持久化，再播放一次庆祝 |

导入他人的 SSR 卡使用“藏品加入”仪式并保留成就来历，不能宣称用户创造了该突破。新来源让已有 Skill 改变时，升级事件只归到发生变化的 Skill。失败、待验证或无变化都有对应反馈，不播放虚假成功特效。动效默认无声；用户关闭动态或系统启用 `prefers-reduced-motion` 时直接展示最终状态与解释，关键内容不能只存在于动画里。

## 6. 场景页面的表达

场景继续保留“目标 → 能力 → 本次卡组 → 完成判断”的产品逻辑，游戏化只服务于发现、收藏、组合和理解方法。

- 场景入口保留名称、搜索和位置，世界观名称不能遮住任务。
- 选中 Agent 时展示其装备槽与本次装备的 Skill；人类 Profile/账户不和 Agent 的装备面板混排。
- Skill 卡检视提供方法边界、来源和成就证据；卡背与等级材质不替代这些信息。
- 本次卡组只展示为当前任务选择的装备，和底部“等级材质对照”分开；选择/移除要即时反馈覆盖和缺口。
- 归类、优先级和 Agent 管理放在次级工具区域；不引入体力、每日任务、抽卡或付费循环。

## 7. 生产接入与验收

正式接入前需要：真实 Skill 身份与评级/成就事件绑定；等级材质 resolver；局部 foil mask；独有纹章和结构变化；事件驱动揭晓状态；桌面 WebView 中的性能、资源和可读性验证。`foil=0` 不能保证模板的卡边、背面没有光谱，固定金材质也需要独立控制。

本轮验收对象是图集和原画一致性：同一装备身份在四档中连续；C 也完整可收藏；C/R 无镭射；SSR 图形有表意；Agent 与人分离；Agent 场景底部标成材质对照；SSR 只作评审对照，生产隐藏；以及不存在“新资料自动升级”的暗示。旧交互原型仅验证历史三主题的布局、翻面、材质与动效想法，不构成精灵概念图已转为可运行 UI 或真实 3D 的声明。


## 2026-09-09 · 装备本体进化修订

用户否决了四档只更改光线和材质的做法。采用“先有装备结构升级，后有卡牌稀有材质”的规则：关闭光效、看缩略图仍应识别等级。

以同一依赖镜头 Skill 为例：C 素木放大镜（单片/木柄）→ R 双轴勘察镜（折叠副镜/校准机构）→ SR 三相解析镜（交叉棱镜/金色解析架）→ SSR 万象重构镜（开放轨道/晶体核心/重连结构）。用形态解释能力变化，禁止同一张原画换色充当升级。SSR 是隐藏的永久 Skill 奖章，不要求当前先达到 SR；进化图只表达造型，不新增授奖路径要求。

C/R 完全无镭射。SR 起开放装备局部镭射与细金边；SSR 才开放全卡镭射和独立重连纹章。装备铜/金金属的普通绘画高光与卡片镭射分开。

页面仍采用鼠标移入微倾、移出回正、点击翻面，静止无自动闪动。当前实现与生成/验证记录见 `prototypes/skill-holo-3d/`；运行入口 http://localhost:4183/ 。


## 2026-09-09 · SSR 神域与晶核生命

最新用户扩展：SSR 的装备内应有元素波动/神魂游动，背景呈现神器连接宇宙、神的空间。此处新增的是 SSR 内部世界的缓慢生命动态，保留鼠标轻微倾斜、点击翻面与不整卡自动闪烁的约束。

晶核局部：青紫元素潮汐、三条可辨识游动神魂，严格限于晶核遮罩；表面刻面与外框保留。空间：独立宇宙神殿原画、开放天球轨道和缓慢沿轨光点。SSR 之外保持原背景与各级原画；不会将稀有性降为全卡通用特效。用户可暂停神域流动；减少动态、背面和不可见时冻结。

最新运行与完整原画提示词/技术输入均保存在 `prototypes/skill-holo-3d/`，访问 http://localhost:4183/ 。当前仍是设计原型与 Skill 永久奖章皮肤，不新增生产授奖规则或个人 Profile 能力证明。

## 2026-09-09 · 凡灵天圣绘图内核

用户提出四品名称后，新增 [凡灵天圣绘图内核 v1](skill-cultivation-visual-foundation-v1.md)：凡凭器、灵载法、天应势、圣成域。它规定器物结构、背景关系、元素轴、器灵与图层合同；这些是原创产品定义，不是假称小说存在统一分类。
